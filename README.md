# 📝 Gerenciador de Tarefas com Manipulação de Arquivos (Python)

> Projeto desenvolvido em Python para demonstrar automação simples, tratamento de exceções, funções e persistência de dados em arquivos de texto (`.txt`).

---

### ⚙️ Funcionalidades
- **Cadastro Interativo:** Permite ao usuário digitar tarefas pelo terminal de forma contínua.
- **Persistência de Dados:** Salva automaticamente as informações em um arquivo de texto local (`tarefas.txt`), garantindo que não sejam perdidas ao fechar o programa.
- **Leitura Dinâmica:** Exibe a lista numerada de todas as tarefas cadastradas até o momento.
- **Tratamento de Erros:** Gerencia situações onde o arquivo ainda não foi criado (`FileNotFoundError`).

---

### 🚀 Como Executar
1. Certifique-se de ter o **Python** instalado na sua máquina.
2. Baixe ou copie o código do arquivo `gerenciador.py`.
3. No seu terminal, execute o comando:
   ```bash
   python gerenciador.py
